Kapitel 1.3 · Fråga 1

Varför delar man upp ett program i funktioner?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 1.3 · Facit 1

Funktioner gör koden lättare att förstå, testa och återanvända.

def hälsa():
    print("Hej!")

Varje funktion bör helst ha en tydlig uppgift.

Kapitel 1.3 · Fråga 2

Vad är en parameter?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 1.3 · Facit 2

En parameter är ett namn som tar emot ett värde i en funktion.

def dubbla(tal):
    return tal * 2

tal är funktionens parameter.

Kapitel 1.3 · Fråga 3

Vad är skillnaden mellan en parameter och ett argument?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 1.3 · Facit 3

Parametern står i definitionen. Argumentet skickas in när funktionen anropas.

def dubbla(tal):     # parameter
    return tal * 2

dubbla(5)           # argument

Kapitel 1.3 · Fråga 4

Vad gör return i en funktion?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 1.3 · Facit 4

return skickar tillbaka ett resultat från funktionen.

def addera(a, b):
    return a + b

Resultatet kan sparas i en variabel eller användas vidare.

Vilken uppgift har en main()-funktion ofta?

Kapitel 1.3 · Facit 5

main() samordnar programmets viktigaste steg.

def main():
    resultat = beräkna()
    visa(resultat)

main()

Detaljerna placeras i mindre funktioner med tydliga namn.
